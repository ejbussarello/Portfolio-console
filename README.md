# Portfolio

Meus mini projetos em C# / .NET, executados no console.

## Como executar
```
dotnet run --project Portfolio.App
```
Ou abra `Portfolio.sln` no Visual Studio e pressione F5.

## Mini projetos
| Projeto | Descrição |
|---|---|
| Verificador de Idade | Informa uma idade e confirma se é maior de 18 anos |

## Como adicionar um novo mini projeto
1. Crie uma pasta em `Portfolio.App/MiniProjetos/NomeDoProjeto`.
2. Crie uma classe que implemente `IMiniProjeto`.
3. Adicione `new NomeDoProjetoProjeto()` na lista em `Program.cs`.
